# Java-Programs
A collection of Java programs covering basic concepts, object-oriented programming, and practical applications

Let's start with a simple Java program: **Addition of Two Numbers**.

## **1. AIM**

To write and execute a Java program to add two numbers and display their sum.

## **2. SOFTWARE REQUIREMENTS**

- Operating System: Windows
- Programming Language: Java
- Software: JDK and Visual Studio Code / Eclipse
- Hardware: Computer or Laptop

## **3. ALGORITHM**

1. Start the program.
2. Declare three integer variables: `a`, `b`, and `sum`.
3. Assign values to `a` and `b`.
4. Add the two numbers and store the result in `sum`.
5. Display the sum.
6. Stop the program.

## **4. PROGRAM**

```

public class Addition {
    public static void main(String[] args) {

        int a = 10;
        int b = 20;

        int sum = a + b;

        System.out.println("First Number: " + a);
        System.out.println("Second Number: " + b);
        System.out.println("Sum = " + sum);
    }
}

```

## **5. OUTPUT**

```
First Number: 10
Second Number: 20
Sum = 30
```

## **RESULT**

Thus, the Java program to add two numbers was successfully executed and the output was verified.
